# 功能说明

这一页讲清产品做了哪些功能、各自的边界与权限规则。界面规范见 [design.md](../design.md)，接口参数见 [接口](接口.md)，检索与拒答的评测见 [检索与评测](检索与评测.md)。

## 产品框架（v0.25，对话优先 + 流式问答 + 多题库 + 自建知识库 + 学习闭环）

> 这一节按 v0.25 的框架写成，之后新增的创作、技能、账号同步、主题与工具以
> [更新记录](更新记录.md) 为准。

入口仍是「问答」：打开就是对话，欢迎态只有一句问候、一排短标签胶囊和一行脚注（照 WorkBuddy 重做，原来那套倒计时 / 连续天数 / 近 7 天统计已撤掉）；输入框自己也单独成卡，模式 / 库 / 人格与发送键都挪到框外一行；侧栏「最近对话」按今天 / 昨天 / 最近 7 天 / 更早分组。主导航为 **问答 / 学习 / 学习空间 / 创作 / 任务清单** 五项（创作在 v0.73 加入），手机底部同名 tab 栏；「今日」暂时退出导航，页面与 `#/today` 路由保留。个人数据（笔记本、精通之路、任务清单、人格、技能、记忆）先写浏览器 localStorage；v0.51 起可在设置页登录账号，登录后按账号同步，没登录时仍只在这台设备。界面按 [design.md](../design.md) 的规范实现（v0.75 起默认琉璃主题）：会话读列 820px，题库 / 考点 / 知识库 / 学习空间总览 / 任务清单 1180px，今日 / 精通之路 / 练习 / 学习空间子页 900px；卡片 16px 圆角与 1px 暖边框。

- **问答**：默认首页，流式输出。多轮对话；用户消息为浅奶油气泡，助手回答不套卡片、直接排版，边生成边显示（阶段提示 + 闪烁光标），引用于逐字校验通过后才出现；校验失败会清空未通过的文字并重试一次，仍失败则整条拒答。生成中发送键原位变停止键，点停止丢弃未校验内容并恢复输入。每条回答展示引用、召回资料、改写后的问题和执行过程，真题和考点都能被引用。输入条左侧的人格胶囊可以切换预设，把「讲解方式」随请求发给服务端；引用校验与拒答规则不变。助手回答下方可「复制」「存到笔记本」。底部是 24px 胶囊输入条 + 圆形发送键，桌面自动聚焦、手机不自动弹键盘。
- **Agent 模式（v0.76）**：输入条新增 **Agent** 开关，开启后改走 `POST /agent/stream`。它先理解问题（寒暄 / 指代不明直接回），再调用 `search_kb` 工具检索，过拒答闸门后生成，最后逐字校验引用；校验不过会换一个检索问题重试一次，仍不过就拒答。回答下方多一行「Agent · N 次 search_kb」，可展开每次工具调用的 query、命中数与耗时，执行过程里能看到各阶段耗时。线程记忆按对话 id 存在内存或 PostgreSQL，换账号拿旧线程号会新建线程。关闭开关就回到原来的问答链路，资料不足时仍可选择通用回答；Agent 模式本身严格按资料作答，不硬编。详见 [Agent 层](Agent层.md)。
- **今日**：辅助工作台（不在主导航，保留 `#/today` 入口）。① 一句话开场，按时间、连续天数、上次学习间隔生成；② 初试倒计时（默认按「12 月倒数第二个周六」估算，可改成本机日期）与「连续 N 天」「近 7 天：问 X · 练 Y」；③ 常驻提问框；④ 今天这一题：优先从错题本、其次从上次提问引用过的真题里挑一道**单选题**，当天固定，答完记「会了/还不太会」；⑤ 接着上次：上次对话 + 上次练习，一键继续。断签不惩罚。
- **学习 · 精通之路**：写目标、勾资料，然后和导师在会话里定大纲。导师先读资料并问 1–4 个问题（基础 / 薄弱点 / 时间 / 讲法），再排成 4–8 个模块、每模块 2–6 个知识点；之后可以继续让它加、删、拆、并，没提到的模块和已掌握进度都保留。详情页左边大纲树、右边会话，切到「学习」按模块逐个走：能配上关联真题的，选完才核对答案，答对才算完成；配不上的可以「读完了，记住这一步」。路线和会话存在本机，刷新后保留。
- **学习 · 练习**：三个标签页。① 随机练习：随机抽题，先作答再展开答案，用「会了/还不会」做本地统计；也可从考点卡片进入「按考点练习」。② 错题本：按科目统计掌握度，支持单题重练和全部重练。③ 10 题小测：按科目抽 10 道单选题组卷，提交即自动判分，错题直接进错题本。
- **学习空间 · 知识库**：自己贴讲义、笔记、手册，切成可引用片段后直接提问，答案按资料原文逐字引用。知识库页只列自建库（公司库 / 个人库），不再列内置 408；408 四科笔记作为共享库「408 考研知识」放在这里（31 篇资料、1683 段，不含真题）。自建库带名称、说明，可加资料、看原文、整库删除。输入条左侧的知识库胶囊切换提问范围（不选就是「408 题库」的真题 + 考点）。详见下节。
- **学习空间 · 题库**：题库改成卡片墙，408 真题是不可删除的**预置题库**（按科目 / 年份筛选、分页、题目详情列出关联考点，仍走服务端语料），下面是用户自己的题库。自建题库带名称、说明与标签；题目按标签筛选，搜索同时命中题干、选项、解析、标签与出处；每道题都记 `source`（标题 + 原文摘句 + 偏移）。自建题库支持删除（连题一起删，二次确认）。
- **题库 · 导入 / 导出**：CSV 表头 `stem,option_a,option_b,option_c,option_d,answer,explanation,tags,source`，四个选项全空即填空题；Markdown 用 `## 题干` + `A.` 选项 + `答案：` / `解析：` / `标签：` / `出处：`。可点选文件或直接粘贴，导入前把行级错误一次列清（行号 + 原因），有错不许导入；题干重复的自动跳过。导出为带 BOM 的 CSV，Excel 直接打开不乱码。
- **题库 · 用资料出题**：粘贴讲义、笔记或手册（80–20000 字），选 3 / 5 / 8 / 10 道，`POST /bank/generate` 调模型出单选题。每道题必须附一段**逐字来自资料**的 `source_quote`（去空白后比对，至少 8 字），对不上的题直接丢弃并说明原因，生成的题数可能少于请求数；题目只落在本机。离线演示模式（未配 `DEEPSEEK_API_KEY`）会如实提示不能出题，不返回假题。
- **题库 · 练习**：自建题库可「开始练习」，随机顺序逐题作答，单选与填空都支持（填空答案可用 `|` 分隔多个可接受写法）；提交后给出对错、解析与出处，并把对错记进题库的答题统计。408 预置题库仍走原来的练习 / 10 题小测。
- **学习空间 · 考点**：四科 → 章节 → 考点卡片，支持全文搜索和章节筛选。卡片是项目自写的考点摘要，标了 `source: self` / `status: draft`，不冒充教材原文；详情里可跳关联真题。章节导航带「考点数 · 涉及真题数」，「考频榜」按关联真题数排出考点热度。
- **学习空间 · 笔记本**：可建多个笔记本，从问答回答一键保存（连同引用原文），也可手写条目；没登录时只在本机，登录后随账号同步；删除不可恢复。
- **学习空间 · 对话**：按更新时间列出全部对话，支持搜索标题与消息内容、重命名、删除、继续。
- **学习空间 · 个性化**：人格预设（一句话风格，可选用到问答）、技能（内置分步推导 / 例题先行 / 结论先行 / 易错点提醒 / 讲完自测，可自建）、学习记忆（目标、目标分数、薄弱科目、学习偏好）。这些只会拼进生成阶段的「讲解方式」，不得改变事实、引用与拒答；没有接入 MCP / CLI，也没有本地工具沙箱。
- **伙伴（已下线，v0.30）**：入口、列表与对话页已从界面移除，用户还没决定要不要做；旧地址 `#/partners`、`#/partner` 一律回问答。人格预设与技能仍在，问答时只把「讲解方式」拼进生成阶段，引用、原题入口与拒答规则不变。
- **任务清单**：三列待办 / 进行中 / 已完成；支持新建、编辑标题与备注、拖动或箭头移动、归档、查看归档并恢复、指定科目、关联一段对话（卡片上可直接跳回）。清单底部显示各列计数，没登录时数据只在本机，登录后随账号同步。
- **设置 · 运行状态**：质量看板从侧栏设置进入。顶部四张 KPI（窗口内拒答数、缓存命中率、本进程问答量、语料规模）；中部拒答原因条形与每日拒答柱图；底部最近拒答。数据源是 `/stats/overview`。

## 自建知识库（v0.25）

把「408 语料」抽象成「知识库」，同一套检索 / 拒答 / 引用校验直接复用到用户自己的资料上。结构照搬 DeepTutor 的三层：**知识库（collection）→ 文档（document）→ 片段（doc chunk）**。

- **物理隔离**：408 题库（真题 + 考点）仍在 `chunks` 表（只读，不在知识库列表里）；用户资料落在 `collections` / `documents` / `doc_chunks` 三张新表，`doc_chunks` 带 `collection_id`、`start_off` / `end_off`。删库靠外键级联，不影响题库语料。
- **408 四科笔记（v0.66）**：`data/curated/408_notes/` 存 26 篇 markdown（MIT 许可的 CS408_Note，含 LICENSE 与上游 README），`scripts/seed_408_knowledge.py` 把它们清洗、按 ≤45000 字切篇，写进共享库「408 考研知识」。脚本按正文 sha256 去重，可重复执行；生产在 API 容器里跑 `python scripts/seed_408_knowledge.py`。入库前剥掉 `![...](...)` 图片外链，图片内容不参与检索。
- **切分**：`kb/chunking.py` 是 DeepTutor `chunk_size=512 / chunk_overlap=50` 的纯标准库实现——先按句末标点攒到目标长度，叠加 50 字重叠；没有标点的长串按 400 字硬切。每段都记原文起止偏移，前端据此把引用原句高亮出来（`GET /collections/{cid}/documents/{doc_id}`，弹窗里滚动到 `<mark>`）。
- **检索**：每个知识库各建一个 `HybridSearcher`（BM25 + pgvector → RRF → Cross-Encoder），`exact_refs=False` 关掉题号解析——用户资料里没有「2019 年第 10 题」，不能因为正则不命中就拒答。精排模型按名字缓存，多个库共享一份权重。
- **prompt**：doc 模式换用 `SYSTEM_PROMPT_DOC`（「用户资料问答助手」），只允许引用给到的资料片段，仍然逐字校验、仍会拒答。
- **不串库**：应答缓存键额外拼上 collection id（内置库沿用原命名空间），断拒答日志带 `|collection:<cid>`，甲的答案不会喂给乙的资料。
- **边界**：单篇 20–50000 字、同库最多 200 篇、同名文档按 sha256 去重；空知识库提问直接回「这个知识库里还没有资料」，不硬编答案。

### 权限与可见性（v0.52，B-lite）

- **全局角色**：`users.role` 只有 `admin` / `member`。第一个注册的账号自动成为管理员；也可以用环境变量 `KB_ADMIN_USERS`（逗号分隔用户名，大小写不敏感）指定，登录或启动时提升。
- **库的可见性**：`builtin`（408 题库，只读，v0.66 起不进知识库列表）/ `shared`（公司库，登录后可读）/ `private`（个人库，只有建库人可读可写）。个人库对管理员也不可见。
- **公司库写权限**：管理员、建库人（`owner_id`）始终可写；`collection_members` 里角色为 `editor` 的成员可以加删资料、改片段，`viewer` 只能读和提问。删库与增删成员比改资料更严，只有管理员和建库人能做（`can_manage`），editor 不能给自己或别人发权限。成员按用户名添加，可随时改角色或移除；建库人不能被移除。
- **服务端判权**：资料、片段、成员、`/ask`、`/chat`、`/chat/stream` 每个入口都重新判权。未登录回 401；已登录但无权回 404，避免用 id 探测别人的库是否存在；内置库写操作回 403。
- **迁移**：存量自建库统一视为 `shared` 且无 owner，只有管理员可写；`collection_members` 为空。个人库与公司库各自去重名称，不同成员的「笔记」可以同名。
- **WeKnora 后端**：它的 ACL 不归本项目管，因此 WeKnora 模式下知识库只有管理员可见可写，也不支持个人库。

## 文件进料与片段管理（v0.49 起自己解析，v0.50 加图片 OCR）

自建知识库不再依赖外部服务：文件上传到本地后由 `kb/parsers.py` 解析，切分、向量、检索、引用校验全在本项目。

- **支持格式**：`.pdf`（pypdf，逐页取文字层）、`.docx`（`word/document.xml` 按段落换行）、`.pptx`（按页码排序，每页前加「第 N 页」）、`.md / .markdown / .txt / .csv / .json / .html / .htm`（HTML 先去掉 `script / style`），以及 `.png / .jpg / .jpeg / .webp / .bmp / .gif / .tif / .tiff` 图片。编码依次试 UTF-8 / GB18030 / Big5，仍失败再交给 chardet，老讲义不乱码。
- **图片 OCR**：`rapidocr-onnxruntime` 跑 PP-OCRv4 的 ONNX 模型，纯 CPU、模型随包分发、不连外部服务。识别前把长边缩到 2400px（超过 4000 万像素直接拒绝），置信度低于 0.5 的行丢掉，按识别顺序换行拼接；识别不到 20 字报「图片里没识别出文字：可能拍得太小、太糊，或者图里本来就没有字」。引擎第一次识别时才加载，`KB_OCR=0` 可关闭；没装引擎时会说明缺哪个包，不假装成功。
- **读不出来就说原因**：旧版 `.doc / .ppt / .xls`、未知扩展名、空文件、超过 20MB、解析后超过 50000 字（提示拆分）都会被拒绝，原因直接显示在上传任务行里；扫描件 PDF 与加密 PDF 各有各的说明，扫描件可以导出成图片再上传走 OCR。
- **状态机**：上传先建 `processing` 文档并立刻返回，后台线程解析完写入片段、状态转 `completed`；失败转 `failed` 并保留 `error`。文本与已有文档重复时同样落 `failed`，理由写「已经在库里」。
- **片段管理**：每篇资料的「片段」打开逐段列表（`#1 #2 …`），可改正文、删除、一键重新切分。修改带 `revision` 乐观锁，两个窗口同时改同一段时后保存的回 409 并要求重新加载；段落下限 10 字、上限 4000 字。
- **界面**：虚线拖拽区上传（点选、键盘也可），任务面板显示大小、进度与状态，最多同时传 3 个，解析状态每 2 秒看一次、最多 10 次，失败可重试。

## 账号与跨设备同步（v0.51）

设置页「个人 · 账号」注册 / 登录后，个人内容会跟着账号走。

- **存什么**：`users`（用户名、PBKDF2 口令哈希）、`user_sessions`（只存 token 的 SHA-256，30 天过期）、`user_data`（每个 localStorage 键一行，值原样存 JSON 字符串）。
- **同步谁**：对话、练习记录、学习进度、笔记本、自建题库、精通之路、任务清单、人格 / 技能 / 记忆、偏好。访问口令、账号 token、同步元数据、当前打开的那段对话和设备级视图状态不同步；知识库资料本来就在服务器的 `collections` 表里。
- **怎么合并**：两边都带 `updated_at`，新的覆盖旧的；本地没有的键拉下来，服务器没有的键推上去。删除写墓碑（`__408_deleted__`），别的设备下次同步会删掉本地那份，不会把旧内容又推回来。
- **换账号**：退出登录不清本机内容；用另一个账号登录时，本机属于上个账号的内容先清掉，避免串号。
- **没有数据库时**：账号和同步退到进程内存，重启即丢；这只适合本地开发，线上必须配 `DATABASE_URL`。
- **安全边界**：口令明文不落盘、不进日志；登录失败同 IP + 用户名 10 分钟内 5 次即锁；同步值单键上限 512KB、一次最多 80 个键；服务端再次拒绝同步凭据类键。

## 可选的 WeKnora 后端（v0.48，默认关闭）

[腾讯开源 WeKnora](https://github.com/Tencent/WeKnora) 的客户端仍保留：服务端配好 `WEKNORA_BASE_URL` 与 `WEKNORA_API_KEY` 才会把用户资料库切到 WeKnora，不配就走上面的本地进料。之所以不再作为默认：官方建议 4C8G，线上那台 2C / 3.7G 跑整套 `app + docreader + postgres + redis` 没有余量，而本项目自己的进料链路已经够用。接入细节见 [WeKnora接入.md](WeKnora接入.md)。

- **只用它做进料与召回**：闸门、生成、逐字引用校验、拒答仍在本项目，不调用它的 `/knowledge-chat`。
- **降级**：WeKnora 连不上时接口回 502 并在界面提示；内置「408 考研」语料永远走本地。

问答检索同时覆盖真题和考点两个库：BM25 + 向量召回 → RRF → Cross-Encoder 精排，引用校验对两类 chunk 用同一套逐字规则。考点只作为概念解释的补充，涉及具体题目答案时以真题解析为准。
