# Agent 层

这一页讲清 Agent 怎么选工具、怎么循环、知识库检索怎么接回原链路，以及记忆与边界。

## 设计依据

参考了主流开源实现的做法：

- **LangGraph** 的 `create_react_agent` / `create_agent`：把工具绑定给模型，模型返回 `tool_calls` → 执行 → 把 `tool` 消息写回 → 再让模型回答；循环有界。
- **LlamaIndex `FunctionAgent`**：工具的名称、描述和参数 schema 就是路由依据，模型按工具描述选择，不靠关键词。
- **Dify Agent**：Function Calling / ReAct 两种策略；知识库作为一类工具挂在 Agent 上，由 Agent 自己决定何时检索。
- **RAGFlow Agentic RAG**：有界 ReAct 循环，检索、改写、网页等都以工具形式注册，并限制迭代次数。

言据采用同样的模式：**用 DeepSeek 原生函数调用，不再维护关键词路由器**。

## 工具

| 工具 | 作用 | 何时用 |
|---|---|---|
| `search_kb` | 在当前知识库检索可引用原文 | 问公司资料、产品手册、制度流程、自己的文档 |
| `kb_overview` | 返回库名、资料数、片段数与资料标题 | 问「这个库有多少资料 / 有哪些文档」 |
| `get_weather` | 天气与今明预报 | 问天气、气温、下不下雨 |
| `get_current_time` | 当前日期、星期、北京时间 | 问今天几号、现在几点 |
| `calculate` | 四则运算、百分比、单位换算 | 数学计算 |
| `run_code` | 进制转换、位运算、白名单表达式 | 代码类计算 |
| `search_web` | 搜索公开网页 | 最新动态、新闻、价格、官网地址 |
| `get_exchange_rate` | 常用货币汇率 | 问美元 / 欧元 / 日元等汇率 |
| `get_air_quality` | 城市 AQI、PM2.5、PM10 | 问空气质量、雾霾 |
| `lookup_ip` | IP / 域名归属与运营商 | 问 IP 归属地、域名解析 |
| `convert_units` | 长度、重量、温度、存储换算 | 单位换算 |
| `fetch_url` | 抓取公开网页正文 | 用户给了链接，或已知官网 |

工具的名称、描述、参数 schema 全部随请求发给模型；服务端不再用「公司」「官网」这类关键词决定路由。

## 状态图

```text
START
  │
  ▼
plan ──(寒暄 / 指代不明)──▶ direct ──▶ END
  │
  ▼
agent（原生函数调用，最多两轮）
  │
  ├─ 模型直接回答 ──▶ END
  │
  ├─ 调用 kb_overview / 天气 / 时间 / 计算 / 搜索 / 抓网页
  │      └─ 执行 → tool 消息回给模型 → 再回答 ──▶ END
  │
  └─ 调用 search_kb
         ▼
      search_kb ──▶ gate ──(证据不足)──▶ refuse ──▶ END
                       │(通过)
                       ▼
                    generate
                       │
                       ▼
                     verify ──(通过)──▶ finalize ──▶ END
                       │
                       ├─ 第一次未通过：换查询重试一次
                       └─ 第二次仍未通过：refuse ──▶ END
```

两个循环都有界：

- Agent 工具循环最多两轮，同一工具同一轮不重复调用；
- 引用校验循环只允许重试一次。

## 知识库检索为什么单独接回原链路

`search_kb` 不是普通工具：它返回的是候选片段，最终答案必须经过拒答闸门、强制 JSON 生成和逐字引用校验。因此模型一旦调用 `search_kb`，服务端就把控制权交回原来的 `gate → generate → verify` 链路，而不是让模型直接拿片段自由作答。

这样：

- 引用仍逐字命中原文；
- 证据不足仍按阈值拒答；
- 校验失败仍换查询重试一次；
- 资料不足仍写缺口日志。

## 记忆

- 默认 `InMemorySaver`；配 `DATABASE_URL` 后切到 `PostgresSaver`。
- 线程按 `thread_id` 存最近 20 条消息；换账号或换匿名客户端拿旧线程号会新建线程。
- 工具循环的中间 `tool` 消息只在本轮使用，不写入长期记忆。

## 边界

- 工具失败会作为失败结果回给模型，由模型说明没取到，不编造结果。
- 网页只抓公网 http/https，挡内网与云元数据地址；外部内容按不可信数据处理。
- 普通知识问题不调用工具，也不向用户解释工具、路由或「没有取到工具结果」。
- 不提供写文件、执行任意命令、MCP 子进程等工具；只读公开网页与白名单计算。
- 单轮最多两轮工具调用，避免 2C 机器上成本和延迟失控。
