# 408 数据管线（D1–D2）

> 目标：把「一台电脑里的真题 PDF」变成「检索库能直接吃的题库 JSONL」，
> 并且保证**每一道题都被人眼核对过一次**。

## 0. 结论先行

**先做「文本 → 结构化」，不要一上来就 OCR。**

- 408 真题在网上有大量**文字版**（docx / 网页 / 排版好的 txt），复制粘贴 30 秒的事，OCR 要调半天还错字连篇。
- 真正稀缺的不是文字，是**答案解析**。真题卷和解析通常是两本书，用题号 join 才是主线工作。
- OCR 是「实在找不到文字版」的兜底，不是起点。

**另一个坑：双栏排版的 PDF 直接抽文本会左右交错。** 优先找 docx 或单栏版；非要用 PDF，先 `pdftotext -layout` 看效果再决定。

## 1. 目录约定

```
data/
  raw/      原始输入（一年一套试卷 txt + 一套答案 txt）
  curated/  人工整理 / 模型补全的内容（标 origin，待人工校对）
  work/     中间产物（草稿、校验报告、校对页）—— 可随时重跑
  out/      定稿 JSONL —— 只进不改，改就回到 draft 重跑
```

命名：`2019_paper.txt` / `2019_answer.txt`。**id 必须带年份**（`2019-408-01`），因为不同年份题号会重复。

## 2. 五步流程

```
真题 txt ──①切题(规则)──> 单题块 ──②抽取(LLM)──> draft.jsonl
                                                    │
答案 txt ──①切答案(规则)──> {题号: 答案+解析} ──join──┘
                                                    │
                                          ③校验(规则) ──> 报告
                                                    │
                                          ④人工校对(HTML) ──> patch.json
                                                    │
                                          ⑤合并 ──> out/2019.jsonl
```

**先跑一遍离线 demo（不需要任何 API key）：**

```bash
python -m pipeline.build --paper data/raw/sample_paper.txt --answer data/raw/sample_answer.txt --year 2024 --provider mock
```

会得到：`data/work/2024_draft.jsonl`、`2024_validate.txt`、`2024_review.html`。

**接真模型（只改一个参数）：**

```bash
set DEEPSEEK_API_KEY=sk-xxxx
python -m pipeline.build --paper data/raw/2019_paper.txt --answer data/raw/2019_answer.txt --year 2019 --provider deepseek
```

**校对完把 patch 合回去：**

```bash
python -m pipeline.build --year 2019 --apply-patch data/work/review_patch.json
```

**答案只有字母、没有解析时（2019 卷 1–40 就是这种情况）：**

```bash
py -m pipeline.analysis --draft data/work/2019_draft.jsonl \
    --out data/curated/2019_analysis.jsonl \
    --apply-to data/work/2019_draft.jsonl
```

这一步基于「题干 + 选项 + 正确答案」生成解析，产物带 `origin`（`ai` / `manual`）和
`generated_at`，落盘后只补空字段；`status` 仍是 `draft`，**不能直接进 `out/`**。
落盘文件就是缓存：重跑只补缺的题，返工用 `--ids ... --replace`。

## 3. 字段规范

| 字段 | 类型 | 规则 |
|---|---|---|
| id | str | `{year}-408-{seq:02d}` |
| seq | int | 1–47 |
| type | str | 1–40 为 `single`，41–47 为 `comprehensive` |
| subject | str | `ds` / `co` / `os` / `cn`；按题号分区定科：1–11 数据结构、12–22 组成原理、23–32 操作系统、33–40 网络；41–42 数据结构、43–44 操作系统、45–46 组成原理、47 网络 |
| score | int | 单选 2；综合题从「本题 N 分」抽，抽不到留 null 等人工 |
| stem | str | 题干原文，**去掉题号和选项**；数学式写 `$...$` |
| options | dict | 仅单选，A–D 四个键；综合题为 `{}` |
| answer | str | 单选单个大写字母；综合题 `""` |
| analysis | str | 解析原文，保留换行 |
| kp_ids | list | 本阶段留空，打标阶段填 |
| figures | list | 图题/图路径；没图 `[]` |
| source_ref | dict | 文件名 + 起始行 + 页码，用来溯源 |
| status | str | `draft` → `reviewed` / `flagged` |

**最重要的一条**：一道题 = 一个 chunk。题干、选项、解析、图**永远不拆开**。

## 4. 机器拦什么（`validate.py`）

| 级别 | 规则 |
|---|---|
| E | 题号不在 1–47 / 题号与题型不匹配 / 题干过短 / `$` 未配对 |
| E | 单选缺选项 / 答案不是 ABCD / 综合题没有参考答案 |
| E | 题号不连续（录满 47 题时）/ 分值合计 ≠ 150（录满时） |
| E | 重复题号 |
| W | subject 未填 / score 未填 / kp_ids 为空 |

**E 不归零，不许进检索库。** W 可以带进下一步，但打标阶段要清零。

## 5. 人拦什么（`review.py` 生成的校对页）

左边是原卷文本，右边是可编辑字段，**只看三样**：

1. 题干有没有丢字、串行
2. 选项有没有错位（尤其 A/B 串位）
3. 答案字母对不对

节奏建议：

- **每次 50 题**。40 分钟后错误率陡增，硬撑等于白干。
- **每题 15 秒**。800 题 ≈ 4 小时，分 2–3 天做。
- **拿不准就点「标记问题」**，别猜。猜错比留空危害大得多。
- 进度存 localStorage，关掉浏览器不丢；导出 patch 后合回。

## 6. 验收门槛（达不到不许往下走）

- [ ] E 级错误 = 0
- [ ] 题号 1–47 连续，无重复
- [ ] 单选 4 个选项非空且互不相同
- [ ] 答案 ∈ {A,B,C,D}
- [ ] 全卷合计 150 分
- [ ] 抽 10% 人工复核，字段准确率 ≥ 98%

## 7. 时间预算（实测口径）

| 环节 | 时间 |
|---|---|
| 找齐文字版真题 + 整理成 txt | 0.5 天（比想象中久） |
| 跑抽取（17 套 ≈ 800 题） | 机器 20 分钟 + 返工 0.5 天 |
| 人工校对 800 题 | 约 4–6 小时（分 3 次） |
| 知识点打标 | 机器初标 + top 200 人工 ≈ 1 天 |
| **合计** | **约 2.5 天** |

这 2.5 天买的是：**后面所有功能（考频图谱、引用、拒答评测）都建立在「数据没错」上**。数据错 1%，评测曲线就是假的。

## 8. 十个必踩的坑

1. **题号跳跃**：OCR 把 13 认成 B，切题器会报 `题号跳跃`，别忽略。
2. **答案速查表**：`1-5 BCADA` 只有字母没有解析，必须另配解析文件。
3. **图题**：408 有大量结构图/电路图/时序图，`figures` 必须存，丢了这题就废了。
4. **双栏 PDF**：直接抽文本会左右交错，优先 docx/网页版。
5. **跨页**：题干在上一页、选项在下一页，按题号切不受影响，但页码要留好。
6. **公式**：LaTeX 原样保留，**绝不让模型「重写」公式**，它会把 `2^{10}` 改成 `2^10`。
7. **选项挤成一行**：`A.xx B.yy C.zz D.ww`，选项正则要支持行内切分。
8. **大题分值不统一**：10/12/13/15 都有，必须从「本题 N 分」抽，抽不到走人工。
9. **综合题有小题 (1)(2)(3)**：不要拆成多题，一个 chunk。
10. **跨年题号重复**：id 不带年份，后面 join 全乱。

- 只用公开流传的真题原文，**解析自己写或找公开版本**；
- 不整库搬运机构（某秀荣、某宇）的付费资料；
