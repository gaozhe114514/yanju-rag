# 目录结构

```
data/
  raw/      原始输入（试卷 txt + 答案 txt）
  curated/  人工整理 / 模型补全的内容（标 origin，待人工校对）
            knowledge.jsonl 为项目自写的 42 张考点卡片（source=self, status=draft）
  eval/     检索评测 query 集（query → gold id）
  work/     中间产物，可随时重跑（已 gitignore）
  out/      定稿 JSONL
pipeline/
  split.py     规则切题 / 切答案
  prompts.py   抽取 prompt
  extract.py   单题块 → JSON（mock / deepseek）
  validate.py  字段级 + 整卷级校验
  review.py    生成校对页、合并 patch
  analysis.py  用模型补选择题解析（单独落盘、可复核、可重跑）
  build.py     全流程 CLI
retrieval/
  chunk.py     JSONL → Chunk，一道题一个 chunk
  tokenize.py  中文 bigram + ASCII 词
  bm25.py      BM25 Okapi（纯 Python）
  vector.py    bge 向量化与暴力余弦索引
  fuse.py      RRF 融合
  rerank.py    词面精排 / bge Cross-Encoder
  search.py    双路召回 → 融合 → 精排
  eval.py      Recall@k / MRR
  cli.py       命令行检索
agent/
  state.py     状态字段、消息上限 reducer、SearchHit / TableStats 序列化
  tools.py     search_kb 工具（JSON Schema、top_k、调用记录）
  prompt.py    重试提示与换查询（LLM / 规则兜底）
  nodes.py     plan / search / gate / generate / verify / refuse / direct 节点
  graph.py     LangGraph 0.6 状态图与条件边（唯一 import langgraph 的地方）
  checkpoint.py 内存 / PostgresSaver 选择与建表
  runtime.py   线程记忆、owner 隔离、SSE 事件与最终结果
answer/
  agent.py     多轮意图识别 + 追问改写（LLM / 规则回退）
  cache.py     应答缓存键、TTL 与响应包装（纯函数）
  gate.py      拒答闸门（分数 + 分差阈值）
  prompt.py    强制 JSON 的 system/user prompt
  providers.py DeepSeek / 离线抽取占位实现
  verify.py    引用逐字校验
  pipeline.py  拒答 → 生成 → 校验 → 重试，并记录分阶段耗时
  stream.py    流式增量解析 answer 字段 + SSE 编码
  qgen.py      用资料出题：严格 JSON prompt + 逐题原文校验（对不上就丢）
  docgen.py    大纲裁剪与 Word / PPT / Markdown 导出
  tutor.py     精通之路导师会话（无状态）
  eval_gate.py 拒答阈值标定
  eval_answer.py 真实生成评测（一次引用通过率 / 拒答分布 / 延迟）
  cli.py       命令行问答
api/app.py     FastAPI 服务（/ask、/chat、/chat/stream、/agent/stream、/bank/generate、/collections、/auth、/me/data、/feedback、/chunks、/knowledge、/stats、/meta、/health、/）
api/accounts.py 账号：注册 / 登录 / 会话（PBKDF2 + token 哈希）与个人数据按时间戳同步
api/access.py  知识库权限（B-lite）：内置 / 公司 / 个人库的读写判据（纯函数）
api/catalog.py 题库筛选、列表/详情序列化（纯函数）
api/metrics.py 进程内问答计数（质量看板用，重启归零）
api/knowledge.py 考点卡片加载、校验、筛选、题目双向关联、章节考频树
api/graph.py   知识图谱：考点 / 真题 / 知识库节点与归属边
api/guard.py   访问口令 + 按 IP 限流 + 每日额度
api/gap.py     拒答缺口日志（JSONL，仅内存模式）
api/feedback.py 反馈标准化、JSONL 落盘与统计（纯函数 + 文件 IO）
kb/
  chunking.py  用户资料切分（512 字目标 / 50 字重叠，保留原文起止偏移）
  parsers.py   本地文件解析：PDF / docx / pptx / md / txt / html / 图片 OCR，编码探测与拒绝理由
  tables.py    表格结构化抽取：openpyxl / python-docx / pdfplumber / bs4，进料时定下行列
  library.py   知识库管理：建库、加资料（切分 + 向量）、删文档、片段改删与重新切分、按库惰性建 searcher
db/
  schema.sql   chunks / collections / collection_members / documents / doc_chunks / users / user_sessions / user_data / meta / gap_logs / answer_cache / answer_feedback 表与索引
  store.py     语料同步、向量召回、SQL 筛选、账号与会话、个人数据同步、拒答与反馈日志、统计聚合
  load.py      手工重建语料（python -m db.load）
  wait.py      容器启动前等 Postgres 就绪
web/index.html 对话优先的单页前端，流式对话，多题库与导入导出，自建知识库与原文高亮，无构建步骤
deploy/nginx.conf  反向代理 + 第二层限流（问答与 /bank/generate 限流）
tools/preload_models.py 构建期预下载模型
Dockerfile / docker-compose.yml / .env.example
tests/      标准库 unittest
docs/       架构、功能、接口、评测、部署文档与配图
```
